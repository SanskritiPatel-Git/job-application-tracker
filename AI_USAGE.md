# AI Usage Documentation

## AI Tool Used

ChatGPT was used to help me with the creation of my Job Application Tracker.

## How I Used AI

Throughout the course of developing my project, I used ChatGPT to receive guidelines on how to build a web application with the use of Python, Flask, and MySQL.

## Examples of Prompts

Examples of the prompts I have asked from ChatGPT include the following:

- How can I connect my Flask application with MySQL?
- How should I create routes that will allow me to add, update, and delete entries from my database?
- How can I store information on the interviews using JSON in MySQL?
- How can I connect the skills that the user enters with those required by the job?
- Why do I have an error in my Python code?

## What Worked Well

ChatGPT allowed me to divide my work into smaller parts, making it simpler to perform.

It was particularly helpful when working with Flask routes, SQL queries, and JSON columns of the database.

## Challenges and Changes

However, there were issues with my project.

There were mistakes with the Python syntax and indentation as well as with database queries that I had to correct and test the application once again.

I also used MySQL Workbench to check whether my information was stored correctly in my database.

## What I Learned

This project helped me gain a greater understanding of the way Flask interacts with MySQL and the way a database stores the information for the web application.

In addition, I have learned about the CRUD operations, JSON data, debugging and testing processes.

AI proved to be quite useful, however, I still had to execute the code and check its performance.
